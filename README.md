PRIME KICKS – E-commerce Web Application
BCA 4th Semester Project
Project Overview:
PRIME KICKS is an e-commerce web application designed for selling footwear. The platform provides a seamless shopping experience for users and efficient management capabilities for admins. It follows a CRUD (Create, Read, Update, Delete) structure, allowing both customers and administrators to interact with the system effectively.

Key Features:
1. User Section (Customers)
🔹 User Authentication: Sign up, log in, and password management
🔹 Product Browsing: View products by category, brand, and price
🔹 Search & Filter: Search bar with filters for price range, brand, and size
🔹 Product Details: Detailed product pages with images, descriptions, and pricing
🔹 Cart & Checkout: Add items to cart, review orders, and proceed to checkout
🔹 Order Management: View past orders and track order status
🔹 Wishlist: Save favorite items for future purchase
🔹 User Profile: Update personal details and manage addresses

2. Admin Section
🔹 Admin Authentication: Secure login for administrators
🔹 Product Management (CRUD): Add, edit, delete, and view products
🔹 Category & Brand Management: Manage product categories and brands
🔹 User Management: View, block/unblock, or delete users
🔹 Order Management: View and update order statuses (pending, shipped, delivered)
🔹 Sales Analytics: Dashboard with sales reports and order statistics

Technologies Used:
✅ Frontend: HTML, CSS, JavaScript
✅ Backend: PHP 
✅ Database: MySQL 
✅ Authentication: Session-based authentication
✅ Deployment: Localhost (XAMPP)

Additional Features (Optional for Enhancement):
✨ Stock Management: Track product availability in real-time
✨ Admin Dashboard: Graphical reports for better insights

Project Goals:
✔️ Implement CRUD operations for users, products, and orders
✔️ Ensure separate sections for Admin and User with role-based access
✔️ Provide a responsive and user-friendly UI
✔️ Secure user data with authentication and validation
